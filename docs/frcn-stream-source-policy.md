# FRCN stream source policy

Preferred evidence order for playback candidates:

1. Direct endpoint exposed by an official FRCN or station-owned player.
2. Direct endpoint exposed by a broadcaster-controlled streaming host.
3. Reputable directory endpoint, independently probed and station-identity matched.

Every candidate must be identity-matched to the FRCN outlet before probing. Shared network programming does not justify assigning one station's stream to another station.
