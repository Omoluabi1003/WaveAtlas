Private, on-device voice cloning for Atlas. The reference recording stays in this browser session and is never uploaded to WaveAtlas, Vercel, GitHub, or a voice API.

Isolated by design. This lab does not replace the stable Atlas voice runtime. The clone model loads only after you explicitly press Load clone engine, so opening WaveAtlas cannot trigger the heavy model or freeze the normal interface.
Clone engine is off.

Engine: open-source Chatterbox running locally through a Web Worker. First model load is large and may take several minutes. Generated speech is short-form and English-focused. If the device cannot sustain the model, this lab fails closed and the normal Atlas runtime remains untouched.
